Web Development
Personal Interview Handbook

Frontend · Backend · Full‑Stack · Web · App

Concise Edition — Short Explanations + Real-World Examples

1. Web Development Fundamentals

What is web development?
Short: Building and maintaining websites and web applications.
Example: Creating Instagram’s feed (frontend) and the logic that saves your likes (backend).
Website vs Web Application
Short: Website = informational. Web App = interactive.
Example: Wikipedia (website) vs Gmail (web app).
Frontend vs Backend
Short: Frontend = what users see. Backend = server + logic + database.
Example: Login form UI = Frontend. Password verification = Backend.
What happens when you type google.com?
Short: DNS → IP → TCP → HTTP request → server → response → browser renders.
Example: Like calling a friend: name (domain) → phonebook (DNS) → number (IP).
What is DNS?
Short: Translates domain names to IP addresses.
Example: The internet’s phonebook.
What is an IP address?
Short: Unique numerical label for each device.
Example: Your home address for the internet.
What is HTTP?
Short: Protocol for transferring data on the web.
Example: The language your browser and server speak.
What is HTTPS?
Short: HTTP + encryption (SSL/TLS).
Example: The padlock icon in your browser when banking online.
What is CRUD?
Short: Create, Read, Update, Delete — the four basic database operations.
Example: Creating a post (Create), viewing it (Read), editing it (Update), deleting it (Delete).
What is MVC?
Short: Model (data), View (UI), Controller (logic connecting them).
Example: Product data = Model, product page = View, code that fetches data = Controller.

2. HTML

What is HTML?
Short: HyperText Markup Language — the skeleton of a webpage.
Example: Like the steel frame of a building.
What is a semantic element?
Short: Tags that clearly describe their meaning (<header>, <nav>, <article>).
Example: Using <article> for a blog post instead of <div>.
div vs span
Short: div = block-level (full width). span = inline (only needed width).
Example: div = a paragraph; span = a word inside a paragraph.
id vs class
Short: id = unique (one element). class = reusable (many elements).
Example: id="logo" for the site logo; class="btn" for all buttons.
What is the alt attribute?
Short: Provides alternative text for images (accessibility & SEO).
Example: Screen readers read alt text for visually impaired users.
What is a form?
Short: Collects user input and sends it to a server.
Example: Login page with email and password fields.
What are data-* attributes?
Short: Store custom data in HTML for JavaScript to use.
Example: <button data-user-id="123"> → JS uses dataset.userId.
Block vs Inline elements
Short: Block = new line, full width. Inline = no new line, content width.
Example: <p> (block) vs <a> (inline).
What is an iframe?
Short: Embeds another webpage inside your page.
Example: Embedding a YouTube video on your site.
Why is HTML structure important for SEO?
Short: Search engines use heading tags and semantics to understand content.
Example: Google ranks pages better when <h1> is used for main titles.

3. CSS

What is the Box Model?
Short: Content → Padding → Border → Margin.
Example: A picture frame: picture = content, mat = padding, frame = border, space around frame = margin.
How to center a div?
Short: Flexbox: display: flex; justify-content: center; align-items: center;
Example: Centering a login card on a page.
What is Flexbox?
Short: 1D layout model for rows or columns.
Example: Navigation bars, card layouts.
What is CSS Grid?
Short: 2D layout model for rows and columns.
Example: Full-page layouts (header, sidebar, main content, footer).
Flexbox vs Grid
Short: Flexbox = components (1D). Grid = page structure (2D).
Example: Flexbox for a navbar; Grid for a dashboard.
What is Specificity?
Short: Browser decides which rule wins: inline > ID > class > element.
Example: #main overrides .text.
How to make a website responsive?
Short: Use media queries, flexible units (%, rem), and viewport meta tag.
Example: A site that adjusts from 3 columns on desktop to 1 column on mobile.
What is a media query?
Short: Applies CSS only when certain conditions (like screen size) are met.
Example: @media (max-width: 768px) { ... } for mobile styles.
Why does z-index not work?
Short: Only works on positioned elements (relative, absolute, fixed).
Example: Adding position: relative to both elements to fix layering.
What are pseudo-classes?
Short: Apply styles based on state (e.g., :hover, :focus).
Example: Button changes color when you hover over it.
What are pseudo-elements?
Short: Style specific parts of an element (e.g., ::before, ::after).
Example: Adding an icon before a link using ::before.
What is CSS Variables?
Short: Custom properties that store values for reuse (--primary-color).
Example: --primary-color: #3498db; used across the entire site.
What is mobile-first design?
Short: Design for mobile screens first, then scale up for larger screens.
Example: Base styles for 320px width, then @media for tablets/desktops.

4. JavaScript

What is JavaScript?
Short: Language that adds interactivity to web pages.
Example: Dropdown menus, form validation, live search.
Data types in JS?
Short: Primitive: String, Number, Boolean, Null, Undefined, Symbol. Reference: Object.
Example: "Hello" (String), 42 (Number), true (Boolean).
var vs let vs const
Short: var = function-scoped. let = block-scoped, can reassign. const = block-scoped, cannot reassign.
Example: Use const for config values, let for loop counters.
== vs ===
Short: == checks value (type coercion). === checks value AND type.
Example: 5 == '5' = true. 5 === '5' = false.
What is hoisting?
Short: Declarations moved to top of scope during compilation.
Example: console.log(x); var x = 5; → works (prints undefined).
What is a closure?
Short: Inner function remembers outer function’s variables even after outer function finishes.
Example: A counter function that remembers its count.
What is this?
Short: Refers to the execution context.
Example: obj.greet() → this = obj. Arrow functions inherit this from parent.
What is the Event Loop?
Short: Manages async operations in JS (single-threaded).
Example: setTimeout callbacks wait in the queue until the call stack is empty.
What is a Promise?
Short: Object representing future completion/failure of an async operation.
Example: Fetching data from an API.
async/await
Short: Syntactic sugar over Promises for cleaner async code.
Example: const data = await fetch('api');
map, filter, reduce
Short: map = transform each element. filter = keep elements that pass test. reduce = accumulate to a single value.
Example: [1,2,3].map(x=>x*2) = [2,4,6].
What is the Spread operator?
Short: Expands iterables into individual elements.
Example: [...arr1, ...arr2] merges two arrays.
What is the Rest operator?
Short: Collects arguments into an array.
Example: function sum(...nums) { return nums.reduce(...); }
null vs undefined
Short: undefined = variable declared but not assigned. null = intentional absence of value.
Example: let a; → undefined. let b = null; → null.
What is DOM?
Short: Tree representation of a webpage.
Example: document.getElementById('id') manipulates an element.
Event Delegation
Short: Attach event listener to parent to handle events on child elements (even dynamic ones).
Example: A ul handles clicks on any li inside it.
localStorage vs sessionStorage
Short: localStorage = persists even after browser closes. sessionStorage = cleared when tab closes.
Example: Saving user theme preference = localStorage.
What is a pure function?
Short: Same input → same output. No side effects.
Example: function add(a,b) { return a+b; } is pure.
What is setTimeout?
Short: Executes code after a delay (in ms).
Example: setTimeout(() => alert('Hi'), 3000); → alerts after 3 seconds.
What is fetch?
Short: Modern way to make HTTP requests.
Example: fetch('https://api.example.com/users')

5. React

What is React?
Short: Library for building UI components.
Example: Facebook’s news feed is built with React.
What is JSX?
Short: HTML-like syntax inside JavaScript.
Example: <h1 className="title">Hello</h1>
What is the Virtual DOM?
Short: Lightweight copy of the real DOM for performance.
Example: React updates only changed parts instead of re-rendering everything.
Props vs State
Short: Props = read-only data passed from parent. State = mutable data inside component.
Example: A user’s name passed to a profile component = Props. A counter = State.
What is useState?
Short: Hook that lets functional components manage state.
Example: const [count, setCount] = useState(0);
What is useEffect?
Short: Hook for side effects (API calls, subscriptions).
Example: Fetching data when component loads: useEffect(() => { fetchData(); }, []);
What is useContext?
Short: Shares state across components without prop drilling.
Example: User authentication state used by navbar, profile, settings.
What is useMemo?
Short: Caches expensive calculations.
Example: Caching a filtered list that only recalculates when the input changes.
What is useCallback?
Short: Caches function references to prevent re-renders.
Example: A callback passed to a child component.
What is React Router?
Short: Manages navigation in a React app (SPA).
Example: /home, /about, /users/:id routes.
What is a Custom Hook?
Short: Reusable logic extracted into a function (useFetch).
Example: useFetch('api/users') returns data, loading, error.
What is Conditional Rendering?
Short: Rendering UI based on conditions.
Example: {isLoggedIn ? <Dashboard /> : <Login />}
What are keys in lists?
Short: Unique IDs for list items to help React track changes.
Example: <li key={user.id}>{user.name}</li>
Controlled vs Uncontrolled Components
Short: Controlled = form data handled by React state. Uncontrolled = data handled by DOM.
Example: Controlled: <input value={name} onChange={...} />.
What is reconciliation?
Short: React’s process of comparing Virtual DOM trees to determine changes.
Example: After state change, React finds minimal updates needed.

6. Backend — Node.js & Express

What is Node.js?
Short: JavaScript runtime built on Chrome’s V8 engine.
Example: Runs server-side JS, powers APIs.
What is Express.js?
Short: Web framework for Node.js.
Example: app.get('/users', (req, res) => res.json(users));
What is Middleware?
Short: Functions that run between request and response.
Example: Logger, authentication, parser.
What is a REST API?
Short: API using HTTP methods for CRUD operations.
Example: GET /users, POST /users, PUT /users/:id.
What is the Event Loop in Node?
Short: Handles async tasks without blocking the main thread.
Example: While reading a file, Node continues processing other requests.
What is package.json?
Short: Project metadata and dependencies file.
Example: Lists express, mongoose, scripts.
HTTP Methods
Short: GET (read), POST (create), PUT (replace), PATCH (partial update), DELETE (remove).
Example: POST /posts creates a new blog post.
Error Handling in Node
Short: Try-catch with async/await, error-handling middleware.
Example: next(err) passes error to global error handler.
What is CORS?
Short: Browser security that restricts cross-origin requests.
Example: app.use(cors({ origin: 'http://localhost:3000' }));
What is JWT?
Short: Stateless authentication token.
Example: User logs in → server returns JWT → client sends it in headers for subsequent requests.
What is dotenv?
Short: Loads environment variables from .env file.
Example: PORT=5000, DATABASE_URL=mongodb://....
What is bcrypt?
Short: Library for hashing passwords.
Example: bcrypt.hash(password, 10).
What is fs module?
Short: File system operations in Node.
Example: fs.readFile('./file.txt', 'utf8', callback).
What is express.json()?
Short: Middleware to parse JSON request bodies.
Example: req.body contains parsed JSON data.
What is process manager (PM2)?
Short: Keeps Node apps running in production.
Example: pm2 start server.js keeps it alive after crashes.

7. Databases

SQL vs NoSQL
Short: SQL = structured tables. NoSQL = flexible documents.
Example: SQL for banking (transactions). NoSQL for social media posts.
What is a Primary Key?
Short: Unique identifier for each row.
Example: user_id in a users table.
What is a Foreign Key?
Short: Links to primary key in another table.
Example: order.user_id references users.user_id.
Types of Relationships
Short: One-to-One, One-to-Many, Many-to-Many.
Example: One user has many orders (One-to-Many).
What is INNER JOIN?
Short: Returns rows with matching values in both tables.
Example: SELECT * FROM orders INNER JOIN users ON orders.user_id = users.id;
What is LEFT JOIN?
Short: All rows from left table, matching rows from right (NULL if no match).
Example: All users, even those without orders.
What is Normalization?
Short: Reduces data redundancy.
Example: Storing user names once, not in every order.
What is an Index?
Short: Speeds up queries.
Example: Index on email column makes WHERE email = ... faster.
What is MongoDB?
Short: NoSQL document database.
Example: db.users.find({ name: 'John' }).
What is Mongoose?
Short: ODM for MongoDB in Node.js.
Example: User.findOne({ email: 'john@example.com' }).
Embedded vs Referenced Data
Short: Embedded = data inside parent document. Reference = ID pointing to another document.
Example: Comments inside a blog post (embedded) vs user ID referencing a users collection.
What is ACID?
Short: Atomicity, Consistency, Isolation, Durability — ensures reliable transactions.
Example: Bank transfer: if one step fails, the whole transaction rolls back.
What is Aggregation in MongoDB?
Short: Pipeline for processing data (like GROUP BY in SQL).
Example: db.orders.aggregate([{ $group: { _id: '$user_id', total: { $sum: '$amount' } } }])
What is Schema in Mongoose?
Short: Defines the structure of a document.
Example: new mongoose.Schema({ name: String, age: Number })
What is a Transaction?
Short: Group of operations that execute as one unit.
Example: Booking a flight and deducting payment in one go.

8. APIs & HTTP

What is an API?
Short: Interface for apps to communicate.
Example: Weather API returns weather data for a city.
What is HTTP?
Short: Protocol for transferring data on the web.
Example: Browser → Server uses HTTP.
What is HTTPS?
Short: HTTP encrypted with SSL/TLS.
Example: Banking websites.
HTTP Status Codes
Short: 2xx = success, 3xx = redirect, 4xx = client error, 5xx = server error.
Example: 200 OK, 404 Not Found, 500 Internal Server Error.
Query vs Path Parameters
Short: Path = /users/123. Query = /users?age=25.
Example: GET /products/123 = specific product. GET /products?category=electronics = filtered list.
What is JSON?
Short: Lightweight data format.
Example: {"name": "John", "age": 30}.
What is API Versioning?
Short: Managing changes without breaking clients.
Example: /v1/users and /v2/users.
What is Rate Limiting?
Short: Limits requests per user to prevent abuse.
Example: 100 requests per minute.
What is Postman?
Short: Tool for testing APIs.
Example: Sending GET /users to see response.
What is RESTful API?
Short: API following REST principles (stateless, cacheable, uniform interface).
Example: GET /users, POST /users.
PUT vs PATCH
Short: PUT = replace entire resource. PATCH = partial update.
Example: Updating a user’s entire profile = PUT. Updating just email = PATCH.
What is Authorization header?
Short: Sends credentials (like JWT) with requests.
Example: Authorization: Bearer <token>.
What is an API Gateway?
Short: Single entry point for multiple APIs.
Example: Routes requests to different microservices.
What is idempotency?
Short: Same request multiple times has same effect.
Example: PUT and DELETE are idempotent; POST is not.
What is WebSocket?
Short: Bidirectional real-time communication.
Example: Chat apps, live notifications.

What is Git?
Short: Version control system.

What is GitHub?

What is a commit?

What is a branch?

Example: feature-login branch for login feature.
merge vs rebase

Example: Merge a feature branch into main.
What is a Pull Request?

Example: Team reviews code on GitHub before merging.
How to resolve merge conflict?

Example: Two devs edit same line → manual fix.
What is .gitignore?
Short: Tells Git which files to ignore.
Example: node_modules/, .env.
git clone vs git fork
Short: clone = copy repo locally. fork = copy repo on GitHub.
Example: Fork an open-source project to contribute.
What is git stash?
Short: Temporarily saves uncommitted changes.
Example: Switch branches without committing WIP.
What is git rebase?
Short: Moves commits to a new base.
Example: Clean up commit history before merging.
What is a HEAD?
Short: Points to the current commit/branch.
Example: Where you are in the repository.

11. Web Security

Authentication vs Authorization
Short: AuthN = who you are. AuthZ = what you can access.
Example: Login = AuthN. Admin access = AuthZ.
What is XSS?
Short: Injecting malicious scripts into web pages.
Example: <script>alert('Hacked')</script> in a comment.
Prevention: Sanitize user input.
What is CSRF?
Short: Tricking authenticated user into unwanted actions.
Example: Malicious site triggers a bank transfer.
Prevention: Anti-CSRF tokens, SameSite cookies.
What is SQL Injection?
Short: Injecting malicious SQL queries.
Example: ' OR '1'='1 bypasses login.
Prevention: Prepared statements.
Why hash passwords?
Short: Prevent plaintext exposure if database leaks.
Example: Use bcrypt to hash password123 into $2b$10$....
What is HTTPS?
Short: Encrypts data between client and server.
Example: Avoids man-in-the-middle attacks.
What is JWT?
Short: Token for stateless authentication.
Example: Authorization: Bearer <token>.
What is CORS?
Short: Restricts cross-origin requests.
Example: Frontend on port 3000, backend on 5000 → enable CORS.
What is Rate Limiting?
Short: Prevents API abuse.
Example: 100 requests per IP per minute.
What is Input Validation?
Short: Check user input before processing.
Example: express-validator ensures email is valid.
Secure Cookies
Short: Set HttpOnly, Secure, SameSite.
Example: Prevents XSS from stealing cookies.
What is .env?
Short: Stores secrets outside code.
Example: API_KEY=abc123.
File Upload Security
Short: Validate file type, size, scan for malware.
Example: Only allow .jpg, .png under 5MB.

13. Scenario-Based Questions

Scenario: Frontend can't connect to backend
Problem: "Network Error"
Solution: Start server, fix CORS, check API URL.
Example: "Backend on port 5000, frontend on 3000. Added CORS."
Scenario: API returns 500
Solution: Check server logs → fix bug (e.g., missing env variable).
Example: "Logs showed missing DATABASE_URL. Added it to .env."
Scenario: Slow database queries
Solution: Add indexes, optimize query, paginate.
Example: "Added index on email field, query dropped from 2s to 50ms."
Scenario: Website loads slowly
Solution: Optimize images, code-split, use CDN.
Example: "Images were 5MB each. Compressed to 200KB, load time improved."
Scenario: User auth failing
Solution: Verify bcrypt.compare, JWT secret, user exists.
Example: "User used wrong case in email. Case-insensitive query fixed it."
Scenario: Two users update same record
Solution: Use optimistic locking or version fields.
Example: "Added a version field. If version mismatch, reject update."
Scenario: 10x traffic spike
Solution: Auto-scaling, load balancer, caching.
Example: "Used AWS Auto Scaling and added Redis cache."
Scenario: Sensitive data exposed
Solution: Sanitize response, remove sensitive fields.
Example: "Removed password and email from API response."
Scenario: Production deployment breaks app
Solution: Rollback, fix bug, redeploy.
Example: "Forgot NODE_ENV=production. Rolled back and redeployed."
Scenario: Malicious file upload
Solution: Validate file type, size, scan.
Example: "Allowed only .jpg, .png. Rejected .exe."

14. Tricky Questions

JS single-threaded but async?
Answer: Event Loop offloads async tasks to Web APIs, queues callbacks.
Example: setTimeout doesn't block other code.
Why need Event Loop?
Answer: Prevents blocking the main thread.
Example: Without it, a fetch would freeze the UI.
Why HTTPS if HTTP works?
Answer: Security — encrypts data to prevent interception.
Example: Banking without HTTPS = passwords exposed.
Why not store passwords plain?
Answer: If database leaks, all passwords exposed.
Example: bcrypt hashing makes them hard to crack.
Why not API keys in frontend?
Answer: Anyone can inspect source and steal keys.
Example: Exposing Google Maps API key leads to abuse.
Why need database indexes?
Answer: Speeds up SELECT queries significantly.
Example: Searching a phonebook: index = alphabetical order.
Why works locally but fails in prod?
Answer: Different env variables, CORS, database URLs.
Example: localhost vs https://myapp.com.
Why does CORS happen?
Answer: Browser same-origin policy prevents cross-domain requests.
Example: Frontend on port 3000, backend on 5000 → CORS block.
Why do React components re-render?
Answer: State changes, props change, parent re-renders.
Example: Clicking a button updates count → component re-renders.
Why prefer ===?
Answer: Avoids unexpected type coercion bugs.
Example: 0 == false = true, but 0 === false = false.
